- **발견 위치**: `app/templates/exam.html` 라인 130~139
- **코드 현황**:
  ```html
  <div class="selector-options">
    <label class="radio-label">
      <input type="radio" name="selected_practical_id" value="Q-PRAC-001" checked>
      <span>17번 문제 선택 (IPTables 방화벽 규칙 분석)</span>
    </label>
    <label class="radio-label">
      <input type="radio" name="selected_practical_id" value="Q-PRAC-002">

    </label>
  </div>
  ```
- **문제점 분석**:
  - `mode="standard"`(제1회 표준 모의고사)에서는 17번이 `Q-PRAC-001`, 18번이 `Q-PRAC-002`이므로 정상 동작함.

  - 이로 인해 `exam.js`의 선택 활성화 로직(`data-qid === selectedId`)이 매칭되지 않아 문제 입력란이 비활성화(`disabled`)되거나, 제출 시 엉뚱한 ID가 서버로 전송되는 중대한 결함이 발생함.
- **수정 권고 (P0)**:
  - `exam.html`에서 하드코딩을 제거하고 `prac_qs` 리스트를 Jinja2 loop로 동적 순회하도록 변경:
  ```html
  <div class="selector-options">
    {% for q in prac_qs %}
    <label class="radio-label">
      <input type="radio" name="selected_practical_id" value="{{ q.id }}" {% if loop.first %}checked{% endif %}>
      <span>{{ loop.index + 16 }}번 문제 선택 ({{ q.category }})</span>
    </label>
    {% endfor %}
  </div>
  ```
